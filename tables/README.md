# Tables

`original/` contains Tables 3–20 from the submitted thesis. Labels are translated into English. Values, blank cells and reported totals are preserved.

`reproduced/` contains results calculated from the recovered questionnaire data. `comparison_with_thesis.csv` compares the main values at the precision printed in the thesis. `dfit_comparison_with_thesis.csv` compares each NCDIF value.

The original reduced CFA values are CFI .964, TLI .959 and p .199. The R output lists candidate item removals because the thesis does not identify all six removed items.

Tables 17–20 concern the open-ended questionnaire. Their values come from the thesis; the underlying response data have not been recovered.
